# Storyboard Skill
流程：`intent → beats → shots → timing → transition → review`。
每镜头必须回答：为什么存在、观众看什么、何时发生、如何进入/退出、声音是否驱动、是否承接前后镜头。
短视频额外检查 hook、节奏密度、字幕占位；纪录片检查信息可读性；TVC 检查产品/品牌 exposure。
